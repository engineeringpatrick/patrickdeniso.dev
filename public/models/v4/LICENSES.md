# V4 3D model sources

The following assets were downloaded from NASA Science on 2026-08-19. The GLB
files were subsequently optimized for the web with Meshopt geometry compression
and WebP textures capped at 1024 px; the checksums below describe those optimized
local files.

NASA's [3D Resources hub](https://science.nasa.gov/3d-resources/) says that its
assets are free to download and use. These assets are governed by the [NASA
Images and Media Usage Guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/),
not CC0: NASA says media used to render 3D models is generally not subject to
U.S. copyright, permits Internet web pages, and asks that NASA be acknowledged
as the source. The assets must not imply NASA endorsement or use NASA
insignia/logotypes.
